# CopyManga Mihon Extension

CopyManga（拷貝漫畫）的非官方 Mihon 擴展。

## 安裝

在 Mihon 中加入以下擴展倉庫：

```text
https://raw.githubusercontent.com/coffee522/extensions-copymanga/main/repo.json
```

加入後刷新擴展列表並安裝 CopyManga。也可以從
[GitHub Releases](https://github.com/coffee522/extensions-copymanga/releases) 手動下載 APK。

## 說明

本項目與 Mihon、CopyManga 官方無關。
